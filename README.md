  <summary><b>📊 Soldi - Gerenciador de Finanças Pessoais</b></summary>

  Aplicação desenvolvida em equipe (4 integrantes) para a disciplina de Técnicas de Programação II na Fatec Praia Grande. Soldi, que significa "dinheiro" em italiano, é um sistema completo de gestão financeira com dashboard interativo, análise por IA e controle total de receitas e despesas.

  <summary><b>🔗 EncurtaUrl - API REST para encurtamento de URLs</b></summary>

  API REST desenvolvida para consolidar meus estudos em Java e Spring Boot, aplicando boas práticas de arquitetura, segurança e design de APIs. URLs muito longas podem ser difíceis de compartilhar e pouco práticas em algumas situações. O EncurtaURL resolve esse problema ao armazenar o link original e gerar uma versão curta, facilitando o compartilhamento e o uso.

  🔐 **Segurança e boas práticas:**
  - Exposição de UUIDs na API para evitar enumeração de recursos
  - Hashing de senhas com Argon2id (recomendado pela OWASP)
  - Autenticação e autorização com JWT
  - Tratamento global e customizado de exceções
  - Validação rigorosa de URL/URIs para evitar entradas inválidas

  ⚙️ **Arquitetura e robustez:**
  - Documentação da API com Swagger
  - Geração de códigos únicos utilizando SecureRandom com estratégia para minimizar colisões
  - Paginação de endpoints para otimização de performance
  - Versionamento do banco de dados com Flyway
  - Containerização com Docker e Docker Compose para facilitar deploy

  🔧 **Stack:**
  Java, Spring Boot, PostgreSQL, Flyway, Docker
